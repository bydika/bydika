## 👨‍💻 About me

I'm a software engineer who enjoys connecting the physical and digital sides of industry. My work spans web applications, APIs, databases, real-time communication, and IoT integration.

- 🔭 Building tools for **manufacturing operations, energy monitoring, and warehouse workflows**
- ⚡ Interested in **real-time systems, industrial automation, and useful data visualization**
- 🌱 Exploring **Flutter, embedded systems, and scalable software architecture**
- 🎯 My approach: **make complex processes easier to see, understand, and improve**
